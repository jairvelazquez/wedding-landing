# Wedding Landing (React + Tailwind)

## Ejecutar en local

```bash
npm install
npm run dev
```

## Build para Hostinger

```bash
npm run build
```

Sube el contenido de la carpeta `dist/` a Hostinger.

## Personalización rápida

- Cambia la fecha en `src/App.jsx` (`weddingDate`).
- Cambia textos y horarios en las secciones.
- Reemplaza URLs de imágenes por tus fotos.
- Cambia el mapa embebido por la ubicación real del evento.
